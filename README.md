# ResumeCraft - Resume Builder [Live Demo →](https://resume-builder-nu-gold.vercel.app/)

A simple, modern and responsive **Resume Builder Web Application** built using **HTML, CSS and JavaScript**.

The project allows users to create a professional resume using predefined templates, preview changes in real time, save their information locally and print/download the resume as a PDF.

---

## 📌 Project Overview

ResumeCraft is a browser-based resume builder designed mainly for:

- College students
- Freshers
- Job seekers
- Internship applicants

The application provides a simple interface where users can enter their personal information, education, experience, projects and skills.

The resume is generated dynamically and displayed in a live preview.

---

## ✨ Features

### Resume Builder

- Personal information
- Professional title
- Email
- Phone number
- Location
- LinkedIn profile
- Professional summary

### Education

Users can add multiple education entries including:

- Degree
- Institution
- Year
- Grade / CGPA

### Experience

Users can add multiple work experience entries including:

- Job title
- Company
- Duration
- Description

### Projects

Users can add multiple projects including:

- Project name
- Technologies used
- Project description

### Skills

Skills can be entered using comma-separated values.
